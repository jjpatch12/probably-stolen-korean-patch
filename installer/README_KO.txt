Probably Stolen 비공식 한국어 패치 1.0 / 2026-10-29

사용법
ProbablyStolen_Korean_Patch_1.0.bat 한 파일만 받으면 됩니다.
게임을 종료하고 BAT를 실행합니다.
[1] 설치를 선택하고 Probably Stolen.exe가 있는 게임 폴더를 선택합니다.
게임 언어는 English로 설정합니다. 게임 폴더를 BAT 위에 끌어 놓아도 됩니다.
[2] 원본 복원은 설치 전 파일로 되돌립니다.
[3] 안내/폰트 라이선스에서 이 설명과 포함된 폰트의 라이선스 전문을 볼 수 있습니다.
[0] 종료. 기본값은 설치입니다.

복원
같은 BAT를 다시 실행하고 [2] 원본 복원을 선택합니다.
설치 전 파일은 게임 폴더의 PSKorean_Backup에 자동 백업됩니다.
백업 폴더를 삭제하면 이 설치기를 이용한 원본 복원을 할 수 없습니다.
설치 후 파일이 다시 변경된 경우에는 자동 복원이 중단됩니다.
세이브 파일과 게임 설정은 수정하지 않습니다.

포함 범위
- 영문 기반 번역 항목 6,680개: 대사, 전화, HUD/UI, 기기·감정, 아이템·설명 등.
- 기존 초벌 번역 전체에 Humanize Korean 검수 및 용어 정리 반영.
- UI·대사: Noto Sans KR Medium, 제목·기기 표시: NeoDunggeunmo(선택 1번).
- 구인·물·장기 간판, 보안카드, 진료소 영업중, 환경 문구 및 서류·가이드 등 이미지 19개.
- 로고·상표·기관 문양, 의도된 서류 오탈자·색상·인쇄 누락·서체 차이는 유지.
- 기존 대사·폰트·이미지를 모두 포함한 누적 배포본.

표시 보정 모드
Mods/PSKoreanEnglishBase가 함께 설치됩니다. 기본 번역·폰트·이미지는 모드 활성화 없이 적용됩니다.
대사 표시 속도와 버튼 글자 넘침 보정 기능을 사용하려면 게임의 모드 메뉴에서
PS Korean English Base를 직접 신뢰·활성화합니다. 설치기는 이 설정을 바꾸지 않습니다.

지원 환경과 확인 범위
Windows 10/11의 기본 Windows PowerShell을 사용합니다. Python·별도 패처 설치는 필요 없습니다.
분석한 PC 원본 빌드(내부 Unity 2021.3.45f2) 전용입니다. 업데이트·다른 패치 등으로
원본 파일 해시가 다르면 파일을 덮어쓰기 전에 중단합니다.
패키지는 원본 게임 파일 전체 대신 변경 데이터와 자체 제작 모드만 포함합니다.
설치 전 원본, 패치 데이터, 생성 결과의 SHA-256을 확인합니다.
게임 플레이 검증은 아직 수행하지 않았습니다. 서류 감정의 실제 표시 배율·난도는 실기 확인이 필요합니다.
한글 판독을 위해 작은 서류 2종의 글자 영역을 소폭 조정했습니다.

글꼴 라이선스 전문은 BAT의 [3] 메뉴를 확인하세요. 본 패치는 게임 본편을 포함하지 않습니다.
